# CineShot 使用说明

CineShot 是挂在 Unity Timeline 上的电影运镜模块。时间轴上一个片段就是一个镜头：片段引用一份镜头模板（`ShotAsset`），播放时模块按模板算出机位、朝向、视场角和焦点，写到一台 Cinemachine 虚拟相机上。镜头之间的叠化、硬切、匹配帧都由模块自己完成，不依赖 Cinemachine Brain 的混合。

- 模块目录：`Assets/CineShot`
- 九种机位的主模板：`Assets/CineShot/Templates/Shots`，其它项目可以直接引用
- 全类型演示：`Assets/CineDemo/Scenes/Demo_RigGallery.unity`（演示不在模块目录里，拷模块时可以不带）

依赖：Timeline、Cinemachine（3.x，或 2.8 降级）、URP（只有景深需要，没有 URP 时其它功能照常）。

---

## 1. 快速接入

1. **主相机**：场景里的 Camera 挂 `CinemachineBrain`，更新方式保持默认（Smart Update）。不要改成 Manual Update。
2. **输出虚拟相机**：新建一台 CinemachineCamera（CM2 是 CinemachineVirtualCamera），不加 Body/Aim 组件。运镜结果写到它上面，播放时它被提到高优先级接管画面。
3. **游戏虚拟相机**（可选）：平时玩法用的虚拟相机。打断、停止时画面从运镜混回到它。
4. **运镜物体**：建一个空物体，挂 `PlayableDirector`、`CineShotRig`、`CineShotPlayer`。
   - `CineShotRig`：「输出虚拟相机」拖第 2 步的相机，「游戏虚拟相机」拖第 3 步的相机。
   - `CineShotPlayer`：导演和运镜绑定留空会自动取同物体上的组件。
5. **时间轴**：给导演建一个 Timeline，添加 `CineShot Track`，轨道绑定拖第 4 步的物体（`CineShotRig`）。
6. **加镜头**：在轨道上右键创建片段，检查器里「镜头资产」选一个模板，比如 `图库_环绕`；「注视目标」「跟随目标」拖场景里的角色。
7. 不播放时拖动 Timeline 播放头，Game 视图就会预览当前机位；进入播放模式，`CineShotPlayer.Play()` 或导演自动播放都可以。

---

## 2. 组件

### CineShotRig（运镜绑定）

| 字段 | 说明 |
|---|---|
| 输出虚拟相机 | 运镜写入目标。播放时启用并把优先级设为 100，停止时恢复原值并禁用 |
| 游戏虚拟相机 | 打断/停止时从运镜混回这台相机的位姿 |
| 与目标最小距离 | 机位离注视点太近时往外推，防止钻进模型 |

轨道的绑定对象就是它。焦点（景深）也由它统一写入 URP Volume：运行时会在它下面生成一个隐藏的全局 Volume（优先级 1000）。

### CineShotPlayer（播放控制）

| 方法 | 作用 |
|---|---|
| `Play(startTime)` | 从指定秒数开始播，会丢弃之前的续播点 |
| `Interrupt(blend)` | 打断：导演暂停，画面在 `blend` 秒内混回游戏相机，记住打断位置 |
| `Resume()` | 从打断位置接着播 |
| `Stop(immediate)` | 停止。`immediate=false` 时先用默认混合时长混回再停 |

`Player` 属性是底层状态机 `CinePlayer`，可以读 `State`（空闲 / 播放中 / 交权混合中 / 已打断可续播）、`CurrentShot`，也可以订阅事件：

```csharp
var player = GetComponent<CineShotPlayer>();
player.Player.OnShotChanged += (oldShot, newShot) => Debug.Log("切到 " + newShot.displayName);
player.Player.OnInterrupted += blend => Debug.Log("打断");
player.Player.OnFinished += last => Debug.Log("播完");
player.Play(0.0);
```

### CineShot Track / 片段

片段检查器里的字段：

| 字段 | 说明 |
|---|---|
| 镜头资产 | 用哪个模板。右键「选中镜头资产」可跳到资产 |
| 片段覆写 | 只改这一条片段、不动模板的参数，见第 5 节 |
| 注视目标 / 跟随目标 | 场景物体。注视决定看向哪里（不填时用跟随）；跟随决定机位锚点或环绕圆心。可以填同一个物体 |
| 转场模式 | 硬切 / 混合 / 匹配帧，写在**进入的那一条**上，见第 6 节 |
| 混合时间 | 只在「混合」且和上一条不重叠时生效 |
| 混入曲线 / 淡出曲线 | 混合快慢。本片段的混入优先，其次上一条的淡出 |
| 样条资产 | 样条机位走的曲线；摇镜时叫「注视曲线」 |
| 机位曲线 / 摇镜速度 | 摇镜专用，见第 4 节 |
| 分镜铺轨 | 分镜表铺轨时写入的内部记录，一般不用管 |

片段默认时长取模板的「默认时长」。片段上的速度倍率（Timeline 自带）可以用。

## 3. 镜头模板 ShotAsset

创建：`Assets/Create/CineShot/镜头资产`，或 `Tools/Cine/镜头库` → 创建 → 按机位。模板只存参数，不存场景引用，场景物体都在片段上绑。

| 字段 | 说明 |
|---|---|
| 显示名称 | 镜头库、时间轴上显示的名字 |
| 机位类型 / 机位参数 | 见第 4 节 |
| 默认时长 | 新建片段的时长 |
| 目标偏移 | 注视点、跟随点相对绑定物体的局部偏移。默认注视抬高 1.6 米（约人头高度） |
| 构图偏移 | 机位沿镜头自己的右、上、前方向挪开，再重新看回注视点。改的是相机位置，不是注视点 |
| 视场角 / 近裁剪面 / 远裁剪面 | 镜头光学参数 |
| 焦点模式 / 焦点距离 / 焦点配置 | 见第 7 节 |
| 混入曲线 / 淡出曲线 | 片段没指定时用的缺省曲线 |
| 优先级 | 两条片段同一时刻开拍时，数值大的做当前镜 |
| 标签 | 只给镜头库搜索用，播放不读 |
| 手持层 | 叠在任何机位上的抖动，见第 8 节 |
| 匹配帧锚点 | 转场为「匹配帧」时，进入第一帧贴住的位姿 |
| 父变体编号 | 用「复制为变体」生成时记下来源，仅作记录 |

## 4. 九种机位

机位参数是一组通用槽位（A、B、C 三个向量，P0–P3 四个小数，I0、I1 两个整数），不同机位含义不同。检查器会按当前机位换成中文名，没用到的槽位不显示。

| 机位 | 行为 | 参数 |
|---|---|---|
| 静态 Static | 停在锚点旁边看注视点 | A 相对锚点偏移（有跟随时随跟随朝向旋转）；P0 偏航、P1 俯仰（度） |
| 轨道 DollyTrack | 片段时长内从 A 平移到 B，一直看注视点 | A 起点、B 终点（世界坐标）；P0 前馈预测秒数；P1 相对轨道侧移；P2 相对轨道抬高；P3 Dutch 倾角 |
| 环绕 Orbit | 绕圆心转圈 | 有跟随绕跟随，否则绕 B；P0 起始方位角（0 = +Z）；P1 角速度（度/秒）；P2 半径；P3 高度；A.x 大于 1 时作结束视场角 |
| 推拉 PushPull | 沿跟随背后方向由 P0 距离推到 P1 距离 | P2 高度；P3 大于 0.5 时视场角同时变到 A.x |
| 摇臂 Crane | 从 A 抬到 B，中间走一段弧 | 有跟随时 A、B 是相对跟随的偏移，整段跟着走；P0/P1/P2 弧线鼓出的 XYZ |
| 过肩 Shoulder | 从跟随者肩后看注视点 | I0 ≥ 0 右肩、< 0 左肩；P0 肩侧距离；P1 肩高；P2 偏航微调；P3 Dutch |
| 手持 Handheld | 基座不动，镜头自己晃，晃完仍盯住目标 | A 相对锚点的基座；P0 位置振幅；P1 频率；P2 俯仰/方位抖动；P3 滚转抖动 |
| 样条 SplineDolly | 沿片段上的样条资产按弧长匀速走，只看注视点 | 没样条时退回 A→B 直线，P3 抬高；P2 前馈秒数（目标明显在动时才生效） |
| 摇镜 Pan | 机位停住，注视点沿弧线扫过 | A 机位（相对跟随）；B、C 注视弧起点终点（相对注视目标）；P0/P1/P2 弧线鼓出；I0 ≠ 0 时机位改走片段上的「机位曲线」。片段上的「注视曲线」优先于 B→C 弧线，「摇镜速度」曲线控制扫的快慢 |

样条资产：`Assets/Create/CineShot/样条资产`。控制点可以在 Scene 视图里直接拖。

## 5. 片段覆写

同一个模板可以给很多片段用。只想改某一条时，打开片段检查器里的「片段覆写」：

- 分三块：**运镜**（机位参数、手持层、构图、目标偏移）、**画面**（视场角与裁剪、焦点与景深）、**其它**（缓动、优先级）。
- 每一项右边的按钮在「模板」和「覆写」之间切换。切到覆写时会先把模板当前值拷进来，再按需修改。
- 没开覆写的项始终跟着模板走，改模板会影响所有没覆写这一项的片段。

Scene 视图里拖手柄、在「镜头配置」窗口里改参数时，默认写到片段覆写；窗口里勾选「改为直接写入镜头模板」则直接改模板。窗口里的「保存至模板」会把本片段已覆写的项拷回模板。

## 6. 转场

转场模式设在**后一条**（正在进入的）片段上，作用在它开始的那段时间：

- **硬切**：一开始就是本镜机位。
- **混合**：和上一条在时间轴上重叠时，重叠多久就混多久；不重叠时用「混合时间」。快慢曲线优先用本片段的混入曲线，没有就用上一条的淡出曲线，再没有就用模板曲线，最后是平滑步进。
- **匹配帧**：进入的第一帧贴住模板的「匹配帧锚点」，随后落到本镜机位。

同一时刻有多条片段时，**后开拍的是当前镜**；开拍时间几乎相同（同刻叠片）才比优先级。

缓动曲线资产：`Assets/Create/CineShot/缓动曲线`，可选线性、平滑步进、三次缓入缓出或自定义曲线。

## 7. 焦点与景深

焦点模式决定「清晰面离相机多远」：

| 焦点模式 | 对焦距离从哪来 |
|---|---|
| 无 | 不驱动，保持上一次的值 |
| 跟随目标 | 每帧取机位到注视点（没有注视用跟随）的距离 |
| 固定距离 | 用「焦点距离」填的米数 |
| 超焦距 | 按焦距、光圈、弥散圈算出超焦距 H = f²/(N·c) + f。例如 35mm f/8 约 5 米，此时从约一半距离到无穷远都清楚 |

焦点配置里的「景深模式」决定画面怎么虚化：

- **散景 Bokeh**：写对焦距离、光圈、焦距（毫米）、光圈叶片，效果真实。
- **高斯模糊**：轻量，清晰带从对焦距离开始，宽度参考光圈。
- **关闭**：关掉 Volume 里的景深。想要画面不虚，改这里，而不是把焦点模式设成「无」。

其它：「对焦阻尼」越大跟焦越跟手；「最大对焦速度」限制每秒变化量；「拉焦时长」是焦点来源切换（比如从跟目标换成固定距离）时的过渡秒数。

跟随目标时变化的是对焦距离，焦距（毫米）不变。两条镜头叠化时，光圈、焦距等参数随叠化过渡；两边都是固定距离时对焦距离也一起过渡；景深模式在叠化中点切换。

景深需要 URP。场景里原有的 Volume 不需要开 Depth Of Field，模块自己的 Volume 优先级更高。

---

## 8. 手持层

模板和片段覆写里都有「手持层」：勾选「启用手持抖动」后，在算好的任何机位上再叠一层晃动，参数含义同手持机位（P0 振幅、P1 频率、P2 俯仰/方位、P3 滚转）。晃完会重新对准注视点，所以目标不会被晃出画面。

「主机位就是手持」和「手持层」不是一回事：前者是机位类型，有自己的基座；后者只叠抖动，不改原机位的轨迹。

## 9. 编辑器工具

| 入口 | 用途 |
|---|---|
| Tools/Cine/镜头库（Ctrl+Shift+Alt+L） | 按名称、编号、标签搜索模板，`#标签` 只筛标签；按机位新建、从 Scene 视角或选中相机新建；复制变体；发送到分镜表 |
| Tools/Cine/镜头配置 | 当前片段的机位、目标、预览时间集中在一个窗口里改 |
| Tools/Cine/分镜表（Ctrl+Shift+Alt+B） | 按行排镜头、时长、间隔、转场，「铺轨」生成或更新轨道片段 |
| Tools/Cine/复制为变体（Ctrl+Shift+Alt+D） | 复制选中的模板，名字加 `_v` |
| Tools/Cine/兼容性与能力报告 | 查看当前 Cinemachine 版本、景深是否可写，可复制诊断信息 |
| CineShot Track 检查器 | 打开分镜表、按分镜表铺轨、检查哪些片段没指定镜头资产 |

**Scene 视图预览**：不在播放模式时，Scene 视图按播放头（或镜头配置窗里的手动时间）解算当前片段，Game 视图同步显示画面。各机位有对应手柄：轨道端点、环绕半径、摇臂起终点和弧线、过肩位置、手持基座和振幅、样条控制点、摇镜注视弧等。播放模式中不接管相机。

**分镜铺轨**是增量的：按「镜头编号#行号」找到已有片段只更新，不会清空轨道。手动改过时长的片段会弹窗问保留哪边。

## 10. 兼容性

- Unity 2021.3 及以上；Unity 6 已验证。
- Cinemachine 3.x 走 CM3 适配；2.8 自动走 CM2 适配，控制台会提示一次。
- 没有 URP 时景深为空实现，运镜照常。
- 代码只用 C# 9 语法。

## 11. 常见问题

**播放时画面没变化**：检查 Rig 上的输出虚拟相机是否指定、轨道是否绑定到 Rig、片段是否选了镜头资产（轨道检查器里「校验镜头引用」可以查）。

**画面一直虚 / 想关掉虚化**：把景深模式改成「关闭」。焦点模式设「无」只是不再更新对焦距离。

**镜头看的位置偏了**：先看模板或覆写里的「目标偏移」，注视偏移默认抬高 1.6 米。角色比较矮或模型原点不在脚底时要改这里。

**同一个角色既要注视又要跟随**：注视和跟随都拖同一个物体，用两个偏移区分（例如注视在头、跟随在脚）。

**叠化时机位突然跳**：确认两条片段在时间轴上确实重叠，或者后一条转场是「混合」且混合时间大于 0。

**打断后点播放从头开始了**：`Play` 总是从给定时间开始；要接着打断处播放用 `Resume`。

## 12. 演示场景

打开 `Assets/CineDemo/Scenes/Demo_RigGallery.unity` 进入播放：

- 顶部显示当前镜头名和一句说明，底下是播放状态、时间、每帧求解耗时。
- 右侧「点播」列出全部片段，点一条就从那里开始播。
- 快捷键：空格播放、I 打断、R 续播、S 停止。
- 内容依次是：九种机位图库 → 景深与焦点（变浅变深、焦点近远、两镜间景深切换、高斯、关闭、超焦距）→ 手持层、构图、缓动、同刻优先级、匹配帧、跟随 → 「走动」章节：人物跑动，九种机位各跟拍一段，每段人物从起点重新出发。
